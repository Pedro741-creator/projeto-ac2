📱 iPhone Compare Brasil
📖 Sobre o Projeto

O iPhone Compare Brasil é um site desenvolvido para comparação de diferentes modelos de iPhone, permitindo visualizar informações importantes como especificações técnicas, preços aproximados e características de cada aparelho.

O projeto foi desenvolvido com foco educacional para aplicar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript, além de práticas de versionamento com GitHub e publicação utilizando Vercel.

🎯 Objetivos do Projeto
Comparar modelos de iPhone em uma única plataforma.
Aplicar conceitos de HTML semântico.
Utilizar CSS para estilização, responsividade e animações.
Implementar funcionalidades interativas com JavaScript.
Praticar versionamento de código utilizando Git.
Publicar um projeto web utilizando Vercel.
